# 专业审查边界

## 先判断是否需要改

站在热解设备制造商及项目从业者视角，重点避免同行一眼能发现的错误。合理的市场规模、进口量、国家份额、增长率、项目投资及一般经营数据可以保留，不要求每项提供证据；没有搜到不等于错误。不要把正常文章改成“需先明确商品编码”“缺少官方口径，不作为依据”等审稿口吻。

只有明确事实、技术、单位/算术、时间或安全错误，以及会导致明显专业误解的表达，才原位修改。替换尽量保持原句式、长度、叙述风格；确需说明适用条件时，在原句加入最短、面向读者的限定。一般文风润色、去 AI 味、增强营销感不是重写授权。

## 知识库与联网

每篇先查本地知识库，同时查询权威网络来源；不要把整个知识库上传网络搜索。检索必要的主题词即可。首次遇到索引，先看表结构、路径、版本与更新时间；FTS 没有结果时可查同义词、SQLite LIKE 或原始 PDF/Word，不能凭索引空结果断言没有资料。

按设备型号、原料种类与实验工况匹配证据；知识库与网络冲突时，优先采用匹配本项目的知识库技术口径，冲突记录留在内部。政策法规、强制标准和安全禁令需要核对现行效力、适用地域及日期；不能用过时内部资料冒充现行法律。此类冲突未能解决时向用户说明，不在正文写协作性备注。

网络优先级：政府/标准发布机构、项目业主或设备方一手公告、行业协会、同行评议研究。保留链接、日期、内部 KB 路径/页码。项目公告中的计划、签约、建设、投产、达产要区分；预测不能改写为已实现。原稿已有读者用来源/图注可保留，新增的修改证据全部放审查记录。

## 必查技术点

| 检查项 | 典型错误与判断 |
| --- | --- |
| 原料和产物 | 废轮胎一般得到油、热解炭/回收炭黑中间品、钢丝、不可凝气；钢丝是回收而非化学生成。塑料/油泥/生物质不能照搬轮胎比例，不能无条件写钢丝产出。 |
| 产率和物料平衡 | 区分湿基/干基、质量/体积、整胎/脱钢胶粒、含水率/灰分。单一工况总量须能解释；各区间上限不必是同一工况，不能简单相加后判假。注意吨、万吨、kg、Nm3、百分比与百分点。 |
| 原料差异 | PE/PP/PS、PVC/PET、混合料、含卤物料、轮胎类型差异明显；不可把某种原料或实验条件的高出油率推广成全部固废的保证值。 |
| 工艺术语 | 热解、燃烧、气化、蒸馏、冷凝、精制不是同一过程；无氧不等于真空/常压；连续/间歇与压力状态不是同一分类。 |
| 产品品质和用途 | 原始热解油不是直接可用车用柴油；冷凝不等于分馏。热解炭不直接等于 N330 等级炭黑；深加工和检测合格后用途才成立。 |
| 气体与能源 | 不可凝气不一概称合成气，热值取决于原料和条件；回炉燃烧不等于所有阶段无需外供能；剩余可燃气不能直接排放。 |
| 产能与运行 | 区分批次处理量、吨/日、吨/年、有效开工天数、运行/冷却/清焦时间；“24小时”不可自动视为所有工艺固定周期。 |
| 环保与安全 | 避免“零污染”“绝不产生二噁英”“重金属全部固化”“所有残渣可施土”等绝对结论；控氧、密封、可燃气治理和污染控制须符合语境。 |
| 经济与项目 | 区分油价和油品等级、税费/运输/处置费、收入与利润、规划产能与达产；只有确实有错才改一般统计数据。 |
| 法规与认证 | 核对标准编号、年份、名称与适用对象；体系认证不等于所有产品合规，CE 不等于所有市场的通行许可。不可把某地/某类项目要求推广成通用规定。 |

这些是判断线索，不是硬编码的统一产率数据库。任何具体比例必须回到适配原料和设备的资料，避免把本次核验数值永久写成通用常量。

## 审查记录

逐篇记录：原稿/哈希、日期作者依据、实际检索的 KB 与网络来源、原句→成稿句→错误理由、冲突和未解决项、图表清单与哈希、输出与备份位置、验证结果。合理数据保留也可以内部简记，但不宣称全部已经逐项证明。

文章正文只出现成稿内容。不得出现“审查发现”“修改建议”“知识库实测证据”“待核实”“依据不足”等编辑输出；遇到原文本来在讨论该词时人工判断，不机械删掉正确引文。
