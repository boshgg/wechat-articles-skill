# HTML 版式标准

设计来源是用户指定的 `金蓬公众号排版_连续式vs间歇式5个坑_修订版.html`，在原项目中可能位于 `html文章/已发表/`。通用实现为 `jinpeng-reference-v2`。只继承视觉语法，不复制参考文章的设备参数、互动文案、主题专用小节或图像。

## 固定视觉

| 元素 | 样式 |
| --- | --- |
| 正文容器 | 白底，100% 宽，最大 677px，居中，常规内侧留白 24px |
| 主色 | 深蓝 `#0b1d33`，金色 `#e0b82f`，薄荷绿 `#74c8ac` |
| 正文/弱化文字 | `#3d4c5f` / `#a8c9e3`，少量红色 `#c63c34` 提示 |
| 正文 | 16px，行高约 2，两端对齐，字距 0，合理换行 |
| 标题块 | 深蓝底、金色顶边、白字约 27px，保留原标题；不额外加入修改说明或营销副标题 |
| 导语 | 有原稿导语时才显示，深蓝底、金色左线；首句约 20px，其余约 15.5px。不从正文抽取重复新摘要 |
| 第一主章节 | 金色左线、深色标题约 25px、小号 TECHNICAL BRIEF |
| 后续主章节 | 深蓝整条色块、金色顶线、白色标题约 23px、薄荷绿 SECTION XX |
| 次级标题 | 原文小标题，深蓝粗体约 17px；三级可 15px |
| 引文 | 浅绿色底、深绿色左线、15.5px，仅用于原有引文或原文重点 |
| 表格 | 原生 table，100%宽，明确网格、表头对比、文本自动换行；不可截成图片 |
| 公司结尾 | 深蓝整宽区、金色顶线、JINPENG INDUSTRIAL、固定四段原文，15.5px / 1.9 |

保留原始章节数与顺序。无图文章不强加封面；只有用户明确的封面，或原稿开头首图有清楚的封面用途，才作为封面。不为填满模板移动正文插图到文章顶部。封面本身已有完整标题时可避免重复标题块，但文档元标题仍保留。不新加公众号操作教程、占位标签、CTA 或免责声明。

## 图片与兼容

- 图片使用原字节 base64 内嵌，HTML 独立预览；设置 `width:100%;height:auto`，不使用裁切容器、固定高度或 object-fit:cover。竖图必要时收窄并居中，不能拉伸。
- 所有正文样式用行内 `style`；无需外部 CSS、JS、网页字体、hover、CSS 变量、伪元素、固定定位、flex/grid 才能读懂的布局。
- 显式设置各文字的颜色、字号、行高；尤其检查深色背景里嵌套 `<strong>` 的颜色，避免深字叠深底。
- 普通要点优先独立 `<p>` 加粗标签，防止编辑器只剩项目符号。确有顺序的步骤可保留编号，但逐项验证文字仍在。
- 正确的 Markdown 加粗形式为 `**标签：** 正文`；一项一段、段间空行。不能出现 `**标签： **`、空列表、代码围栏包住整文、裸 Markdown 符号。
- 数值不能因自动拆导语而截断，例如 `4,010`、`1.84`、`40%`。图注保持在原图旁，不能被当作导语。
- 只改变版式，不增删表格行列；过宽表格先换行、调列宽。合并单元格/嵌套表必须专门保真处理，不能静默展平成错误表格。

## 微信发布边界

在浏览器打开 HTML，复制渲染后的文章富文本，而不是 HTML 源码或 Markdown。微信可能过滤标签/样式/data URI 图；实际工作中需要在编辑器粘贴后复核，必要时从保留的原图上传插回原位置，仍不改图片。是否可导入、如何粘贴以当前编辑器实测为准。交付中明确“浏览器验证”与“公众号后台实测”不同，不能保证自动识别或自动发布。
